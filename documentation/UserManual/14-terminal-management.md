# Terminal management

Place terminal symbols (`IEC.TERMINAL`, `IEC.TERMINAL.PE`) with the strip tag (e.g. `-X1`) and a terminal number. **Synchronise terminal strips** creates the strip definitions; there you can set levels, terminal types and jumper groups.

The **terminal diagram** is generated from actual wiring: for each terminal it lists the panel-side (inner) and field-side (outer) connections, wire numbers and jumpers.
