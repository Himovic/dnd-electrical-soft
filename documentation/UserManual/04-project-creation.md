# Creating a project

1. **File ▸ New project** (Ctrl+N).
2. Choose a **template**: Blank, Industrial installation, Manufacturing plant, Oil and Gas, Water treatment, Power distribution, Building installation, HVAC systems, Industrial automation, Renewable energy.
3. Enter project number, name, customer, company and engineer. These values feed every title block.
4. Click **Create**. The project opens with a cover sheet and the template's sheets.
5. Save it with **Save as** (Ctrl+Shift+S). Projects are single `.dndx` files.

Templates set the nominal voltage, earthing system and standard profile (IEC 60364, IEC 60204-1 or NF C 15-100) used by calculations.
