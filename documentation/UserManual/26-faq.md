# Frequently asked questions

**Are the demo projects real?** No. Customers, products, prices and part numbers in demo projects are fictional and marked as such.

**Does the software certify compliance with IEC/NF C standards?** No. Calculations implement documented formulas and are preliminary engineering aids.

**Can I open DWG files?** Not in this version; use DXF.

**Can several engineers work on one project?** File locking prevents simultaneous editing. A central PostgreSQL storage foundation exists for future multi-user deployments.

**Where is my data stored?** In your `.dndx` project files (SQLite databases) and the application data folder.

**Is an internet connection required?** No for local work. Online licence activation, floating licences, field connections (Modbus TCP, MQTT), webhooks and the Claude assistant need network access.

**Where is the complete manual?** The PDF user manuals (English and French) are installed in the `Manual` folder of the installation directory and listed in the Start menu.
