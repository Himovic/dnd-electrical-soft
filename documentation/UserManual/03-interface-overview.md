# Interface overview

- **Ribbon tabs** (top): Home, Project, Drawing, Insert, Engineering, Calculation, Reports, View, Tools, Help.
- **Left panel**: Project Explorer, Symbol Browser, Equipment browser, Layers.
- **Centre**: drawing tabs — several sheets can be open at once.
- **Right panel**: Properties inspector for the selected object (device data, wire data, attributes).
- **Bottom panel**: Command line, Validation messages, Output log.
- **Status bar**: cursor coordinates (mm), zoom, snap/grid/ortho state, active sheet, current tool prompt.

## Themes and modes

View ▸ Theme switches between light and dark; the accent colour is configurable in Tools ▸ Settings. *Beginner mode* hides advanced ribbon groups; *Advanced mode* shows everything.

## Finding commands

- **Command palette** (Ctrl+Shift+P): type any command name.
- **Search everywhere** (Ctrl+F): finds sheets, devices, wires, cables, PLC tags and help articles.
- Hover over a button to see a tooltip with its shortcut.
