# Interface overview

- **Ribbon tabs** (top): Home, Project, Drawing, Insert, Engineering, Calculation, Reports, View, Tools, Help.
- **Left panel**: Project Explorer (sheets, devices, cables, terminal strips, PLCs, motors, cabinets, calculations, revisions, attachments), Symbol Browser, Search results, Layers (visibility, lock, print).
- **Centre**: drawing tabs — several sheets can be open at once.
- **Right panel**: Properties inspector for the selected object (device data, wire data, attributes).
- **Bottom panel**: Command line, Validation messages, Output log.
- **Status bar**: last message (e.g. grid/snap/ortho state after toggling), active sheet and cursor coordinates (mm). The current tool prompt is shown in the top-left corner of the drawing.

## Themes and modes

View ▸ Theme switches between light and dark; the accent colour is configurable in Tools ▸ Settings. *Beginner mode* hides the advanced ribbon groups (Modify, Import, Archive, Sheet exchange, Data exchange); *Advanced mode* (View tab or Settings) shows everything.

## Finding commands

- **Command palette** (Ctrl+Shift+P): type any command name.
- **Search everywhere** (Ctrl+F): finds sheets, devices, wires, cables, PLC tags and help articles.
- Hover over a button to see a tooltip with its shortcut.
