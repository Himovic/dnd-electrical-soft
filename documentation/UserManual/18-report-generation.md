# Report generation

Reports ▸ Generate offers:

- **Drawing set PDF** — vector PDF of all sheets with cover page.
- **Report book PDF** — project summary, drawing index, BOM, equipment, motors, loads, cables, cable cores, wiring list, terminal diagram, PLC I/O, cross-references, cabinet layouts, calculations, validation and revisions.
- **Excel workbook** — one worksheet per list, with filters and frozen headers.
- **CSV** lists.
- **Handover package** — all of the above plus DXF per sheet, engineering XML and project JSON, zipped.

Options: language (English/French), company logo, header and footer text, page numbering, date format, accent colour and report selection. Every document carries the product attribution *Powered by D&D | Data&Development*.
