# Cable management

Create cables with type, number of cores, cross-section, length, origin, destination and route. Cores receive IEC 60445 style markings (BN, BK, GY, BU, GNYE) or numbers.

Assign wires to cable cores from the wire's properties or the cable editor. The schematic shows the core next to the wire number (e.g. `-W1:BN`).

Reports: **cable schedule** (used and spare cores) and **cable connection report** (core → wire → from/to pins).
