# Release notes

## Version 0.4.0 (2026-11)

First integrated release:

- 2D CAD engine with undo/redo, snapping, layers and DXF exchange.
- Electrical schematics with real connectivity, wire numbering, device tagging and cross-references.
- Built-in IEC-style symbol library and custom symbol libraries.
- Cables, terminals, PLC I/O, cabinet layout and BOM.
- Engineering calculation engine with transparent reports.
- 22 validation rules.
- PDF, XLSX, CSV, DXF, SVG, PNG, JSON and XML exports; handover packages.
- Five demonstration projects.
- Help center with search, tutorials and documentation administration.

Known limitations are listed in the repository README.
